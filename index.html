    本程序使用 ES 模块与浏览器本地数据库，直接以 file:// 打开时浏览器会拦截模块加载，并可能禁用麦克风与存储。

    1. 已安装 Node.js：在项目目录运行 npm start（无需 npm install）。
    2. Windows 也可以直接双击 start.bat。
    3. 只有 Python：运行 python start.py。

    启动后访问 http://127.0.0.1:8168 即可使用。
